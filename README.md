# Money Blast — Light & Simple

Keep using your existing Money Blast site address to keep local saved contacts, photos, templates and settings available. All existing mb_* storage keys are preserved. No messages are sent by this update.

For an existing site: replace index.html. The full ZIP also provides the manifest, icons and service worker for PWA installation. Upload all extracted files to your repository root when updating the full install package. Keep the current site/repository separate from Voice to Pocket and Dynamic Q.

Everyday flow: Add Contact, Write Message, Send to a Group. Search and text/email actions are on the contact list. Optional filters, contact details, and message attachments expand when needed. Contact reordering, call, reply logging, edit, opt-out and delete are under More actions. Other features remain under More Tools.

Group messages open your messaging/email app one recipient at a time; you review and send. Existing permission checks are retained. Sheets sync still uses your existing settings. A fresh browser has an empty contact list rather than sample people. Existing stored records are not removed. This is a presentation and workflow update; SMS/email provider behavior is unchanged.

Deploy to HTTPS. Install from the live site when your browser offers installation. Real sending, phone import, Sheets sync and installation require testing on your own device/account.
